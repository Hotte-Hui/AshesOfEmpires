# ASHES OF EMPIRES: THE LAST WINTER — Preproduction v0.2

**Status:** Planning and production specifications only. No UE5 game, executable, gameplay screenshots or performance benchmarks have been created or tested.

## Creative direction
- UE5, Blender-assisted where useful; visual identity grounded in the four bundled user reference images.
- Detailed atmospheric pixel art; cinematic 2D, 2.5D and selected pixel-rendered 3D scenes.
- Alexei Morozov (Soviet Union) and Matthias Adler (Germany), with scripted narrative character switching.
- Fictional 1964 Europe after an inconclusive war; both regimes portrayed critically. The fictional Great Hall exists only in this alternate timeline.
- Long-term six-chapter campaign ambition, **first milestone is a polished 20–30-minute vertical slice**.

## Start here on the PC
1. Extract this folder to a clean project location.
2. Open `technical/CLAUDE_HANDOFF.md` in Claude Code and instruct it to read the entire package.
3. Keep `references/` available locally. Reference images are for inspiration only; do not redistribute or embed them in the released game.
4. Run `python tools/validate_preproduction.py` for static JSON checks.
5. Follow `technical/RENDERING_PIPELINE.md` before bulk scene production.

- `docs/ART_DIRECTION.md`: reference-driven look and palettes.
- `docs/WORLD_RULES_AND_TIMELINE.md`: fictional canon and critical historical framing.
- `docs/ASSET_SPECIFICATIONS.md`: prioritized asset list.
