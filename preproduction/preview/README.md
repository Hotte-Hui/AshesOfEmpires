# Offline HTML Vorschau

`story_flow_preview.html` demonstriert **nur** die Zustandsabfolge der beiden Quests und Entscheidungen in einem Browser. Diese einfache Weboberfläche ist ausdrücklich **kein UE5-Spiel, keine 3D-Grafik und kein ästhetisches Qualitätsziel**. Sie nutzt die v3 JSON-Inhalte zum Erstellen eines unabhängigen HTML/JS-Previews ohne CDN oder Internet.

Diese Vorschau ist nützlich, um fehlende Story-Ziele und unverständliche Entscheidungen vor der Engine-Umsetzung zu erkennen. Das eigentliche Spiel muss mit UE5 gebaut werden.
