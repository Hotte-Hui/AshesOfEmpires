- **All art, audio, music, text and code are original work created for this project** by its generator scripts

  reproduces the files byte-for-byte.

  Courier Prime, PT Mono — downloaded from the official google/fonts repository; licence texts ship next to them).
  See the UI part below for URLs and hashes.
- **No sample, texture, sound or image from the internet or from the reference images was copied, traced or
  embedded.** `documentation/references/` is an internal style study only, excluded from git and from the build.
- No purchased assets, no subscriptions, no AI-generated media from external services.

  written from the sources listed on each card; they were researched and then independently fact-checked.

### Rendering contract (replaces TECHNICAL_ARCHITECTURE §2 for round 2)
```
Main (Node, main.gd)
 ├─ World (SubViewport)        hi-res: (640+2)k x (360+2)k, transparent, snap_2d_transforms OFF, vertices ON
 │   ├─ LevelRoot              levels / 2D cinematics / the 3D hall
 │   ├─ Camera (world_camera)  zoom = k, position = drawn - (1,1)   (1 world px overscan margin)
 │   └─ Post/Grade (ColorRect) in-viewport post: low-res path only (hidden in hi-res)
 ├─ Graded (SubViewport)       hi-res only: GradeStage (TextureRect = World texture, grade material, from_texture)
 ├─ WorldView/Display          shows Graded (hi-res) or World (low-res) at canvas -3,-3, size 1926x1086
 ├─ UI (CanvasLayer 10), Overlay (CanvasLayer 5)   unchanged
```
* **k = `Game.view.world_scale`** = round(3 × window content scale) when that is an integer and the stretch offset
  is whole (1080p → 3, 1440p → 4, 2160p → 6, 720p → 2): the world maps **1:1 onto physical pixels**. Other sizes:
  k = floor(3 × scale), stretched by the canvas (old behaviour). Re-evaluated on every window resize.
* **Camera**: `pos` continuous top-left (world px); `drawn` = `pos` rounded to 1/k world px; everything that is
  positioned by the render code lands on whole viewport pixels → camera, parallax and actors move in **single
  screen pixels**, texels stay crisp k×k blocks. `Game.world_to_ui()` unchanged (uses `drawn`).
* **Snapping**: Godot's `snap_2d_transforms_to_pixel` snaps in *world units* (verified by
  `camera_snap_probe`), so it is **off** in the hi-res path; `snap_2d_vertices_to_pixel` stays on. Free-moving
  nodes are rasterised on the nearest viewport pixel.
* **Low-res path** (any Node3D in LevelRoot, e.g. the Great Hall; also legacy `--capture-world` runs, see below):
  642×362, zoom 1, pixel-locked gameplay camera, sub-pixel remainder of cinematic moves and of the hall's lens
  shift via `PixelView.set_fraction` — identical to the round-1 pipeline.
* **Post** (`post_grade.gdshader`): palette snap + 4×4 Bayer, grade, vignette dither and grain are evaluated per
  world texel (`px_scale` = k, `dither_origin` = camera in viewport px). The dither threshold comes from the
  **texel code** that opaque sprites write into the framebuffer alpha (`pixel_sprite.gdshader`, 16 levels in
  0.03..0.87): the dither sticks to each layer's/actor's own texels → no dither crawl on parallax layers during
  pans, no 1-px slivers on actors between world pixels. Pixels without a code (alpha ≤ 0.02 or ≥ 0.97: other
  materials, translucent overlays over nothing, empty background) fall back to a playfield-anchored Bayer.
  `hint_screen_texture` copies force alpha = 1 (verified by `camera_alpha_probe`), hence the second stage.
* **World sprite materials** (assigned by PixelView to every Sprite2D/AnimatedSprite2D entering the World without
  a material of its own; layer_stack assigns them with plane-consistent `dither_anchor`): opaque binary-alpha
  textures → coded material (`TexelLight.coded_material()`); translucent lit sprites → per-texel lighting only.
  Coded sprites are watched every frame and fall back to normal blending while their effective modulate alpha
  < 1, so fades keep working. A node that brings its own material is never touched.
* **Followed actor**: `player.gd` interpolates its drawn position between the last two physics states
  (`get_visual_position()`), the camera chooses its pixel (`draw_pos_for`): it keeps its screen pixel while
  camera and player move together (TARGET_TOL 1 screen px), keeps its world pixel while standing and never steps
  back against its walking direction.
* **Follow model**: dead zone (6×4 px), look-ahead 40 px after 10 px of committed walking direction (own
  critically damped spring ω = 2.1/s, held when stopping), exact critically damped spring ω = 5.2/s (no
  overshoot, frame-rate independent). `reduced_motion`: ω ×2, look-ahead ×0.6 (ω ×2.2), dead zone ×0.6.
  `tween_to` keeps its API (Tween on `pos`, sub-pixel smooth); `release()` / `set_top_left()` stop a running
  `tween_to` tween.
* **Screen-space content inside the World** (a CanvasLayer under a level or cinematic laid out for 642×362) is
  scaled by k automatically (meta `pv_no_autoscale` opts out). `get_viewport().get_visible_rect()` inside the
  World returns the hi-res size — use `Game.view.world_scale` if a script needs it.

#### Public APIs (kept + new)
* Camera: `target, bounds, pos, drawn, VIEW, follow_offset, cinematic, set_bounds, clamp_pos, desired, snap_now,
  set_top_left, tween_to, release, top_left, moved` — new: `vel, look_ahead, dead_zone, smoothing,
  look_smoothing, px_scale(), draw_pos_for(node, visual), refresh()`.
* PixelView: `setup(vp, graded = null), set_fraction, world_to_ui, set_shake` — new: `is_hires(), set_hires(on),
  world_scale, capture_world_image() -> Image (640×360, graded), resolution_changed(k)`.
* Main: `world, level_root, camera, grade, view, ui_layer, overlay` — new: `graded`.
* LayerStack (static): `tex(path)` (now Symbols-resolved), `map_path(path, "_n"|"_e")`, `canvas_tex`,
  `light_texture`, `_v2`; instance: `layers_by_name`, `decals_by_name`.
* TexelLight: `coded_material(), material(), apply(item, anchor, cell), apply_tree(root, cell), set_blended(item,
  blended), is_coded(item), is_opaque_pixel_art(tex)`.

#### scene.json additions (layer_stack.gd)
```json
"layers": [ {"name": "shafts", "file": "shafts.png", "blend": "add", "alpha": 0.8, ...} ],
"fx":     [ {"type": "anim_sprite", "file": "fx/steam.png", "alpha": 0.85, ...} ],
"decals": [
  {"name": "banner_1", "file": "decals/decal_banner_1.png", "pos": [412, 96], "layer": "room", "z": 1},
  {"name": "plaque",   "file": "decals/decal_plaque.png",   "pos": [600, 250], "layer": "playfield", "base_y": 262},
  {"name": "poster",   "file": "decals/decal_poster.png",   "pos": [900, 40], "parallax": [0.45, 0.0], "z": -73,
   "lit": true, "normal": true, "emission": false, "emission_strength": 0.22, "alpha": 1.0, "flip_h": false,
   "frames": 1, "fps": 6}
]
```
* `file` relative to the scene.json folder, resolved through `Symbols.pick()` (`name_hist.png` when historical
  symbols are on); maps: `name_hist_n.png` / `name_hist_e.png` if present, else `name_n.png` / `name_e.png`.
* `pos` = top-left in world px **at camera (0, 0)** (same convention as layers).
* `layer` (optional): name of a layer → the decal becomes a child of that layer (inherits its parallax; `z` is
  relative to the layer, default 0 = drawn above it). `"playfield"` → y-sorted in the Playfield with sort key
  `base_y` (default `pos.y + height`). Absent / unknown → own holder with `parallax` ([x, y] or a number,
  default [1, 1]) and absolute `z` (default 0).
* `lit` (default true; unlit decals ignore 2D lights), `normal` (default true, uses the `_n` map if present),
  `emission` (+ `emission_strength`), `alpha`, `flip_h`, `frames`/`fps` (horizontal strip animation).
* `LayerStack.decals_by_name[name]` gives the node (e.g. for a story script that hides a banner).

### Runtime (scripts/core/audio.gd, default_bus_layout.tres)
* Buses: Master (HardLimiter, ceiling −0.5 dB) ← Music, Ambience, SFX, UI (all send to Master).
* `Audio.play_ambience(id, fade := 1.5)`, `Audio.play_music(id, fade := 2.0)`, `Audio.stop_music(fade := 2.0)`,
  `Audio.sfx(id, volume_db := 0.0, pitch_var := 0.05)`, `Audio.ui(id)` exactly as in TECHNICAL_ARCHITECTURE §7.
  Equal-power crossfades; any number of overlapping changes is safe (each track keeps its own player while fading);
  same id = no restart; `""` fades out; missing files are a silent no-op with one warning.
* `sfx("step_gravel")` picks a random variant `_1.._4` (never the same twice in a row) with ±5 % pitch.
  `ui("move"|"select"|"back")` → `ui_*`; `ui("type_tick")` → `type_tick_1..3`; `ui()` also accepts any SFX id.
* Extras: `stop_ambience(fade)`, `sting(id, duck_db := -9, fade := 0.35)` (one-shot cue over the music, ducks it,
  restores when done — intended for `mus_choice`), `sfx_loop(id, key, volume_db, fade)` / `stop_sfx_loop(key, fade)`
  (e.g. `fire_crackle_loop`), `has_sound(id)`, `preload_sound(id)`, `current_music()`, `current_ambience()`,
  `set_bus_volume_linear(bus, v)`. Music/ambience stay uncached (freed after fading out); SFX are cached.
* Looping music: `mus_karsk`, `mus_berlin`, `mus_menu`; all `amb_*`; `fire_crackle_loop`. One-shot cues:
  `mus_choice`, `mus_hall_reveal`, `mus_finale_x1` (`current_music()` becomes `""` when a cue ends by itself).
* Volume settings: `Audio` applies `master/music/ambience/sfx/ui_volume` from the `Settings` autoload at start and on
  `Settings.changed`. (Settings' own `apply()` maps keys with `String.capitalize()` → "Sfx"/"Ui", which do not match
  the bus names "SFX"/"UI" from §7; Audio covers this, so no change to settings.gd is required.)
