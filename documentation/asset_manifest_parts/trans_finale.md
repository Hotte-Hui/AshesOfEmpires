## What it is
A 47.5 s animated, skippable montage that replaces the three crossfaded X1 stills. It ties the two protagonists
together softly: the same night minute (Berlin 23:47 / Karsk 1:47 Moscow time), mirrored framings (Konrad's window
faces east, Alexei's west — they "look at each other" across the cuts), the same snow carrying the cut from one
city to the other, a clock tick answered by telegraph clicks, two lamps over one border map, the red C-17 route
drawn from Karsk west to Berlin, and both lamps going out until only the line is left.

## Insignia (TECHNICAL_ARCHITECTURE §12.4)
In-world iconography of the regimes on official documents only, inside the critical narrative; never UI or reward.
Every insignia layer exists twice with identical frame rects; the montage picks the variant from `ctx.symbols`.

| Layer | neutral file | `_hist` file |
|---|---|---|
| Berlin office stamp on the approved plan (violet ink) | `b_close/stamp.png` — state eagle on a wreath with the fictional Reichssiegel pillar | `b_close/stamp_hist.png` — the same eagle, Hakenkreuz on point in the wreath |
| Letterhead on the typed request (paper in the machine / carried / in the tray) | `b_close/paper.png`, `b_close/letter.png` (pillar) | `b_close/paper_hist.png`, `b_close/letter_hist.png` (Hakenkreuz) |
| Ministry of Railways plate on the signal-box wall | `k_close/plaque.png` — star over the fictional gear-and-wheat | `k_close/plaque_hist.png` — star over hammer & sickle, "МПС" |
| Round stamp in Alexei's freight ledger (red ink) | `k_close/stamp.png` (gear-and-wheat) | `k_close/stamp_hist.png` (star, hammer & sickle) |

The small symbols are hand-pixelled masks (7×7 / 9×9, `cine_finale_kit.SYM`), the eagle is rasterised from a
polygon description (`eagle_shapes`); all original drawings.

## Runtime
`scenes/cinematics/finale/Finale.tscn` (root script `scripts/cinematics/finale/finale_montage.gd`, snow node
`finale_snow.gd`): `signal finished` (exactly once), `configure(ctx)`, `play()`, `skip()` (idempotent), plus
`seek(t)` for tests. Everything visual is a pure function of the montage time. Reduced motion: static cameras, no
flicker. Grade preset `grade_preset = "finale"` (falls back to `default`).
