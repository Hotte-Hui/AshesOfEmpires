# Asset manifest — UI (area: ui)

Owner: UI specialist · Date: 2026-11-04 · Engine: Godot 4.7.2 · All entries below were produced or obtained on 2026-11-04.

Everything in this area is **original work** generated procedurally by project scripts, except the four OFL font families
listed in §1. No pixel, shape or colour sample was taken from `documentation/references/` (internal style study only).
Palette values come from `tools/pixelgen/pg.py` (karsk / archive ramps) as defined by `documentation/ART_DIRECTION.md`.

## 3. Pixel-art UI kit (generated)

Generator: `tools/pixelgen/gen_ui.py` (`py -3 -P tools/pixelgen/gen_ui.py`; deterministic, no network; uses
`tools/pixelgen/pg.py` without modifying it). Every texture is drawn at 1:1. Runtime copies of frames/icons/puzzle sprites
are stored x3 nearest-neighbour because StyleBoxTexture cannot scale (1 art pixel = 3 UI pixels at 1080p, 4 at 1440p, 6 at
2160p); world-pipeline pictures (title backdrop, portrait placeholder, plan placeholders) stay 1:1 and are scaled x3 at
runtime. The 1:1 sources live in `assets/ui/src_1x/` (gdignored) with `src_1x/manifest.json`. Licence: original, project-owned.

Design notes: deep navy panels `#0B1C24` at ~91 % with a 1-px copper rule `#BA775B` and chamfered corners (opaque variant
for stacked dialogs); paper `#E6DEC2` with hairline edge, folded corner and drop shadow; rubber stamps pre-rotated at 1:1 (no
rotated sprites at runtime); signal cards are fictional enamel plates (square / circle / triangle, shape-coded); overlay marks
A = ring, B = diamond (colour independent); title backdrop = dithered night with a faint skyline of both cities (slab blocks,
silos, crane, the fictional dome without any insignia) and one warm signal lamp as the only warm light.
